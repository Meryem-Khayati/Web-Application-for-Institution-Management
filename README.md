# Web Application for Institution Management

## Description
Cette application web permet la gestion complète d’un établissement académique. Elle offre une plateforme centralisée pour administrer les filières, les étudiants, les résultats académiques, les emplois du temps ainsi que les annonces.

Le projet a été développé avec une architecture moderne basée sur **Spring Boot (backend)** et **React (frontend)**, en mettant l’accent sur la sécurité, la performance et la scalabilité.

---

## Fonctionnalités principales

- **Gestion des étudiants**
  - Ajouter, modifier, supprimer et consulter les étudiants

- **Gestion des filières**
  - Organisation des filières et spécialités

- **Gestion des résultats**
  - Saisie et consultation des notes et résultats académiques

- **Gestion des emplois du temps**
  - Planification et affichage des cours

- **Gestion des annonces**
  - Publication d’annonces importantes pour les étudiants

- **Authentification & Autorisation**
  - Système sécurisé basé sur JWT
  - Gestion des rôles et des accès avec Spring Security
